Server Settings

These values control server heartbeat leases. Worker command timeouts are set per project when creating or replaying a project.

Proxies

Workers route outbound traffic through the proxy assigned to their project. Pick a proxy at project creation; new projects default to no proxy.

Capabilities

MCP servers and skills that projects can attach per task stage (bootstrap / explore / reason). This page reads and writes dispatch.resources.yaml; project creation snapshots the selected config into structured execution config tables. Probe checks server-visible paths, URLs, and stdio command configuration. It does not guarantee the worker can execute the capability successfully.

Enabled for task stages
Sub-skill requires_ids (auto-load within the same task stage)

AI Profiles

Shared AI worker profiles that new projects (and replays) can attach to as primary or fallback. Authentication env vars are fixed by worker type and applied automatically.

Worker type is locked for existing profiles. Create a new profile to switch.
